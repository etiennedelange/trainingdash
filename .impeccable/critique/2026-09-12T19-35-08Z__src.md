## Design Specificity Verdict

**LLM assessment:** Genuinely authored, not templated — the token architecture (closed sport palette, all-numbers-are-mono, two-mode theme swap) shows real discipline, confirmed live. But the product's most distinctive promise — a console that reacts the instant an activity lands — has zero visible expression. The reserved Arrival Amber/Gold gradient and toast-in keyframe exist in CSS and nowhere else. A WebSocket push today just silently swaps rows via refetch(). Outside the token system, the shell could belong to any small internal tool.

**Deterministic scan:** `impeccable detect --json src public` ran clean — exit 0, zero findings.

**Visual overlays:** Not available this run due to MCP session contention between the two parallel assessments. Live findings below come from Assessment A's direct CDP inspection, not an overlay script.

## Overall Impression

A disciplined token architecture undercut by two concrete gaps: a confirmed routing bug that breaks every bookmark/PWA shortcut except the home route, and a fully-specified "live arrival" moment that was designed on paper and never wired into any component. Closing the second gap is the cheapest fix here — the tokens and animation already exist.

## What's Working

1. The theme-token architecture is exemplary — every color/radius/shadow is a CSS custom property; confirmed live that light mode re-themes every surface with zero visible seams.
2. The mono-for-numbers rule creates the "telemetry" feeling on its own, even in degenerate cases.
3. The closed sport palette is disciplined — four fixed colors, one visual grammar, explicit gray fallback.

## Priority Issues

**[P0] Hard navigation to any non-root route renders a blank white page**
- Why it matters: Confirmed live — /activities, /progress, /activity/123 all return 200 with correct HTML/JS and no console errors, yet #root stays empty. Client-side nav works fine on the same routes.
- Fix: Investigate the TanStack Router deep-link/hydration path against how the dev/Worker setup serves the SPA shell for nested paths.
- Suggested command: /impeccable audit

**[P0] The live-arrival moment has no visual expression**
- Why it matters: The product's headline feature is indistinguishable on screen from a stale page that auto-refreshed. Arrival Amber/Gold and toast-in are fully specified and unused.
- Fix: Apply animate-toast-in (or the reserved warm gradient) to the specific ActivityRow just upserted, or surface a transient toast using those tokens.
- Suggested command: /impeccable delight

**[P1] Generic, disconnected error state on data failure**
- Why it matters: "Could not load activities." shows identically for network failure and "never connected Strava" (401); the only remedy sits in the sidebar footer, spatially disconnected from the error line.
- Fix: Distinguish unauthenticated from real fetch failures; render the Connect CTA inline in the content area for the unauthenticated case.
- Suggested command: /impeccable clarify

**[P2] Only one designed focus style in the entire codebase**
- Why it matters: grep -rn "focus" src returns exactly one hit. Every other nav link, tab, ActivityRow, ThemeToggle, and button relies on the browser default focus ring.
- Fix: Define one :focus-visible treatment (e.g. 2px --color-accent ring at the component's own radius) as a shared class.
- Suggested command: /impeccable audit

**[P2] Dim Gray / Warm Taupe fail contrast where used for real information**
- Why it matters: Measured: dark --color-faint (#5b6472) on card is 2.90:1; light equivalent is 2.27:1 — both under the 4.5:1 AA floor. Applied to substantive copy (iOS caveat, Coach's "Thinking…" line, chart axis labels).
- Fix: Bump --color-faint to clear 3:1, or promote real-information uses to --color-muted.
- Suggested command: /impeccable audit

**[P3] Coach's error text repurposes a closed sport-palette color**
- Why it matters: Reuses Strength Magenta for an ad hoc error color — not licensed by the Closed Sport Palette Rule.
- Fix: Define a dedicated, restrained error/warn token.
- Suggested command: /impeccable polish

## Persona Red Flags

**Alex (Power User)**: No keyboard shortcuts or dense/compact view. Live-arrival gives no positive confirmation; a silently-dropped WebSocket could leave Alex staring at a stale feed with total confidence it's live.

**Sam (Accessibility-Dependent)**: Confirmed contrast failures (2.9:1 / 2.27:1) on text Sam needs to read. Single ad hoc focus style app-wide. No aria-live region anywhere in src — a screen-reader user gets zero notification when new data silently arrives.
